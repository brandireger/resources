# Early Visions of Florida — Reading Tracker

A static GitHub Pages site for tracking reading of the 50 excerpts in USF's
[Early Visions of Florida](https://digitalcommons.usf.edu/early_visions_bucket/) collection.

- Links to every item page and PDF
- Read / reading / unread status, stars, per-text notes, peoples named, quotes and a confidence score
- Research log and questions panel
- Export / import notes as JSON (progress is stored in the browser's localStorage)

Tiers (A/B/C) are a triage for studying Indigenous peoples and their relationships. They are not part of USF's catalog.
Years are as listed on the USF page.

Files: `index.html`, `data.js` (the 50 items). No build step.
